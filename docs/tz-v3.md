  аренде и не в частной собственности.
- Ограничения/обременения: арест, запрет регистрационных действий, ипотека, сервитут (публичный/частный),

## 10. Нефункциональные требования и ограничения

- Достоверность выше полноты: лучше «нет данных» с ссылкой, чем догадка. Все ИИ-формулировки проходят
  через правила пороговых значений (п. 1), а не свободный текст.
- Антибот/право: Росреестр блокирует автоматические запросы (капча), Авито — парсинг запрещён; архитектура —
  официальные выгрузки, открытые данные, свои базы, ручные шаги пользователя с помощью. Отдельный зум по
  данным Росреестра (Влад предложил).
- Учётные данные третьих лиц (ЛК Росреестра Андрея) не принимать и не хранить; при необходимости — отдельная
  учётная запись проекта.
- Персональные данные: ФИО правообладателей не хранить (как в R12/R13), только статусы и маски.
- Производительность: до 300 номеров в подборке (уже есть), новые источники не должны тормозить проверку —
  ПЗЗ/торги/межевание подтягиваются фоном с отметкой «обновляется».
