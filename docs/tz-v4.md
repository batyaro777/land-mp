## 4. P2 — интерактивная карта (главный визуальный запрос Андрея, 36:24–40:50)

4.1 Карта как map.ru/pkk + «Торги на карте»: регион → кадастровые округа → кварталы. Цвет

вердикт), нажатие на квартал → список лотов квартала и его рынок.

по делу).
Этапы: (1) точки лотов уже есть в свёрнутой карте списка — развернуть по умолчанию, цвет по
вердикту, кластеры; (2) округа и кварталы раскрасить по индексу ликвидности (границы — слой
кадастровой карты НСПД); (3) выбор квартала на карте как фильтр и запуск сбора по нему.
