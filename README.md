# landcheck — проверка подборки земельных участков

Брокер загружает кадастровые номера с ценой и площадью из объявлений. Сервис сверяет каждый
участок с публичными данными НСПД (nspd.gov.ru, бывшая ПКК) и выдаёт таблицу
**стоп / проверить / ок** с причиной и источником по каждой строке. Это модуль М1 из
[ТЗ на MVP](docs/tz-mvp.md).

## Что проверяется

`landcheck rules` печатает каталог. Кратко:

| ID | Правило | Уровень |
|---|---|---|
| R01 | Номер не найден в НСПД или не похож на кадастровый | стоп |
| R02 | Статус: архивный / снят с учёта → стоп, временный → проверить | стоп / проверить |
| R03 | Границы в ЕГРН не установлены (487-ФЗ, с 01.03.2025 сделку не зарегистрируют) | стоп |
| R04 | Категория земель против цели (дом на сельхозземле → стоп; исключения: садовый ВРИ по 217-ФЗ, дом фермера на КФХ → проверить) | стоп / проверить |
| R05 | ВРИ против цели с учётом категории: ЛПХ в населённом пункте — дом можно, ЛПХ на сельхозземле — стоп; садоводство — дом по 217-ФЗ, огородничество — стоп; конфликт → стоп, не подтверждает → проверить | стоп / проверить |
| R06 | Площадь в объявлении против ЕГРН: >10% проверить, >25% стоп | стоп / проверить |
| R07 | Площадь декларированная, не уточнена межеванием | проверить |
| R08 | Цена < 30% кадастровой стоимости — подозрительно дёшево | проверить |
| R09 | Цена за сотку < 50% медианы подборки | проверить |
| R10 | Пересечение с ЗОУИТ: СЗЗ, затопление, кладбище для жилья → стоп; остальные → проверить | стоп / проверить |
| R11 | Территориальная зона ПЗЗ против цели: класс зоны по названию (индивидуальная / многоэтажная / садоводство / сельхозугодья / производственная …), матрица цель × зона; без названия в НСПД — «проверить по ПЗЗ» | стоп / проверить / ок |
| R12 | Собственность публичная или неразграниченная (не указана — справочно) | проверить |
| R13–R17 | Дубли, бюджет, диапазон площади, устаревшие данные, нет кад. стоимости | справочно |

Цель задаётся как действие покупателя: построить жилой дом, дача, личное хозяйство, ферма,
отдых, торговля, производство, многоквартирный дом (`--purpose izhs|snt|lph|farming|recreation|
commerce|industry|multifamily`). Проверка идёт на трёх уровнях — категория земель, ВРИ,
территориальная зона ПЗЗ — и в отчёте сводится в блок «Можно ли здесь: …» (обратная связь
брокера Антона М., 13.10.2026: один и тот же ВРИ в зонах Ж-1 и Ж-2 разрешает разное).
НСПД для терзон часто отдаёт только реестровый номер — тогда сервис честно просит сверить
зону по карте градзонирования ПЗЗ, а не додумывает.

Матрица «цель × категория» и нюансы ВРИ — в `landcheck/rules/purpose.py`, классы зон и
матрица «цель × зона» — в `landcheck/rules/zones.py`, пороги — в `RulesConfig`
(`landcheck/rules/engine.py`). Это стартовая версия для пилота; правила Анастасии вносятся туда же.

## Установка

```bash
uv venv && uv pip install -e ".[dev]"      # или: pip install -e ".[dev]"
.venv/bin/landcheck --help
```

Доступ к НСПД зависит от сети (проверено 10.10.2026): из облачного контейнера Claude Code и
из Вьетнама соединение не устанавливается, с VPS в Нидерландах отвечает за 1–3 с. Рабочая
схема с ноутбука: SOCKS-туннель через свой сервер и флаг `--proxy`:

```bash
ssh -D 1080 -N -f vps                      # туннель через VPS (хост из ~/.ssh/config)
landcheck fetch 77:05:0001005:19 --proxy socks5://127.0.0.1:1080 --out fixtures/
```

Прокси можно задать и переменной `PYNSPD_CLIENT_PROXY`. Библиотека `pynspd` отключает проверку
TLS намеренно: у НСПД сертификат Минцифры.

## Использование

```bash
# подборка из CSV/XLSX/текста, цель ИЖС, бюджет 3 млн, результат в XLSX
landcheck check podborka.csv --purpose izhs --budget 3000000 --out out/istra.xlsx

# запрос текстом вместо флагов
landcheck check podborka.xlsx -q "ИЖС до 3 млн, от 8 до 12 соток" -o out/istra.xlsx

# номера прямо в аргументе
landcheck check "50:09:0060202:101; 2 500 000; 10 сот" --purpose izhs --md

# скачать сырые ответы НСПД в JSON (фикстуры, отладка)
landcheck fetch 50:09:0060202:101 50:09:0060202:102 --out fixtures/

# офлайн-прогон по сохранённым JSON
landcheck check podborka.csv --fixtures fixtures/ --purpose izhs

# ежедневный автотест формата НСПД по эталонным номерам (код выхода 2 = дрейф)
landcheck monitor --update          # снять снимок
landcheck monitor                   # сравнить с ним
```

Вход: колонки «кадастровый номер», «цена», «площадь» (единицы читаются из заголовка:
«сот», «м2»; «тыс»/«млн» в цене). Без заголовка — построчно «КН; цена; площадь».

Выход XLSX: листы «Подборка» (отсортирована: ок → проверить → стоп), «Флаги» (по одному
на строку с источником), «ЗОУИТ» (вид, название, реестровый номер, полный текст ограничений),
«Источники и поля» (каждое поле: источник и дата получения),
«О проверке» (параметры, медиана, дисклеймер).

## Веб-кабинет

```bash
landcheck invite --count 5          # коды приглашений для брокеров пилота
LANDCHECK_PROXY=socks5://127.0.0.1:1080 landcheck web --port 8000
```

Открыть http://127.0.0.1:8000. Вход: email и пароль (регистрация с выбором роли — покупатель,
продавец, брокер) или код приглашения пилота. Роль задаёт домашнюю страницу и навигацию;
права администратора (модерация): `landcheck admin <email или id>`. Страницы:

* **Подборки** — вставить номера или загрузить CSV/XLSX, задать цель, бюджет и площадь;
  проверка идёт в фоне с прогрессом, результат — таблица с фильтром по вердикту,
  сортировкой и выгрузкой XLSX/CSV. Запрос словами и список номеров можно надиктовать
  (кнопка «Голосом», до 60 с): в браузере распознаёт Web Speech API, запасной путь — сервер
  (Groq Whisper бесплатно или локальный faster-whisper); текст показывается для правки до отправки.
* **Отчёт по участку** — карточка, карта с контуром и ЗОУИТ, флаги с источниками,
  тексты ограничений, «Локация» (окружение, вода, негативные факторы, ориентир по соседям),
  «Регион», ценовой ориентир, чек-лист перед сделкой. Кнопка «Ссылка для клиента»
  даёт публичную страницу под брендом брокера, «Скачать PDF» — печатную версию с шапкой
  (бренд и логотип задаются в «Профиль и логотип»).
* **Один участок** — разовая проверка по кадастровому номеру.
* **Объявления** (кабинет продавца) — текст из фактов НСПД и заметок продавца
  (заметки можно надиктовать; при ключе Gemini заголовок и текст собирает ИИ), подсветка
  противоречий с кадастром, фото, выгрузка в Avito XML. Подтверждение права: продавец
  загружает выписку ЕГРН или договор с собственником, модератор решает на `/admin/listings`,
  файлы после решения удаляются. Подтверждённое объявление публикуется на витрине `/market`
  и по публичной ссылке `/l/<id>`.
* **База участков** `/market` — публично, без входа: только объявления с подтверждённым
  правом и текстом, сверенным с кадастром; фильтры по региону, типу, цене и площади.

**Бесплатный стек ИИ** (решение 19.10.2026): языковая модель — цепочка бесплатных провайдеров
(`GROQ_API_KEY` достаточно: gpt-oss-120b и Qwen 3.8 на Groq; запасные OpenRouter `:free`,
Mistral); блок «Регион» ищет через свой SearXNG (`SEARXNG_URL`) или DuckDuckGo без ключа,
скачивает страницы и отдаёт модели только найденное с номерами источников; голос — Web Speech
API в браузере, на сервере Groq Whisper или `faster-whisper` (сборка с `--build-arg ASR_LOCAL=1`).
Gemini остаётся опцией (`LANDCHECK_REGION=gemini`, `GEMINI_API_KEY`).

Переменные окружения — в `.env.example`. Хранилище кабинета — SQLite (`LANDCHECK_DB`),
фото объявлений и логотипы — рядом в `uploads/`, документы на проверке — в `proofs/`
(не статика, видят только владелец и модератор, удаляются после решения). Новые колонки
добавляются к старой базе при старте (`ALTER TABLE`). Персональные данные правообладателей
не хранятся.

### Деплой в Docker

```bash
cp .env.example .env            # заполнить LANDCHECK_SECRET, LANDCHECK_BASE_URL, при необходимости LANDCHECK_PROXY
docker compose up -d --build    # слушает 127.0.0.1:8010, снаружи — через reverse proxy (Caddy, nginx)
docker compose exec landcheck landcheck invite --count 5
```

Прод: https://land-mp.dnai.engineering на VPS 176.124.203.214, каталог `/opt/land-mp`, порт публикуется
на `172.19.0.1:8020` (override-файл), домен через `mcp-caddy`. Обновление:
`cd /opt/land-mp && git pull && docker compose up -d --build`. Если под рукой нет машины с SSH,
обновление делается через коннектор MCP VPS: задача Клавдию (`klavdiy_task`) с этими же командами,
статус по `klavdiy_task_status`, логи и рестарт контейнера — `logs` / `restart`.

## Данные и кэш

* Ответы НСПД кэшируются в SQLite (`~/.landcheck/cache.sqlite`), повтор не чаще раза в 7 дней
  (`--ttl-days`, `--refresh`). Если НСПД недоступна — отдаётся кэш с пометкой даты.
* На участок 3–4 запроса: карточка, вкладка ВРИ, пересечение контура с ЗОУИТ и с
  территориальными зонами. `--no-zones` оставляет один-два.
* Официального API у НСПД нет; используется библиотека `pynspd`. Отсюда `landcheck monitor`.
* Персональные данные (ФИО правообладателей) НСПД не отдаёт и сервис не хранит.
